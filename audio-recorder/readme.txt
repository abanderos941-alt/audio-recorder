====================================================================
АУДИО РЕКОРДЕР — краткий гайд
====================================================================

Записывает звук с микрофона и системного звука (то, что играет из
динамиков — например голоса собеседников в Zoom) одновременно и
сохраняет в MP3/WAV. Умеет автоматически резать запись на отдельные
файлы по паузам в речи — удобно для последующей транскрипции (Whisper
и т.п.).


--------------------------------------------------------------------
ЧТО ЗА ФАЙЛЫ
--------------------------------------------------------------------

Программа состоит из трёх файлов на Python:

  install_rec.py   Установщик. Запускается один раз при первой
                    установке на новом компьютере — проверяет систему
                    и ставит недостающие библиотеки.

  recorder.py       Ядро записи (класс Recorder: захват звука,
                    определение речи/тишины, сохранение файлов).
                    Отдельно не запускается — его использует
                    recorder_ui.py.

  recorder_ui.py     Программа с окном (GUI). Именно её ты запускаешь
                    каждый раз, когда хочешь записывать.

Все три файла обязательны и должны лежать в одной папке.
recorder_settings.json (настройки) создастся сам при первом запуске.

Необязательно, но может пригодиться:

  list_devices.py   Печатает список всех аудиоустройств с их индексами:
                    все устройства (вход/выход, частота дискретизации),
                    отдельно — loopback-устройства (через них рекордер
                    захватывает системный звук), и какие микрофон и
                    динамики стоят по умолчанию.
                    Пригодится для диагностики или чтобы вручную выбрать
                    конкретное устройство в настройках, если "Авто"
                    выбирает не то, что нужно.
                    Запуск: python list_devices.py


--------------------------------------------------------------------
ТРЕБОВАНИЯ К СИСТЕМЕ
--------------------------------------------------------------------

  - Windows 10 или 11 (x64). Программа использует WASAPI — это
    Windows-технология захвата звука, на других ОС не работает.
  - Python 3.10 или новее (https://www.python.org/downloads/).
    При установке Python обязательно оставь галку "tcl/tk and IDLE" —
    без неё не будет окна программы.
  - Библиотеки: pyaudiowpatch, lameenc, numpy — их ставит install_rec.py
    автоматически, вручную ставить не нужно.
  - Микрофон и звуковыход (обычные встроенные/USB устройства,
    отдельных драйверов не требуется).


--------------------------------------------------------------------
УСТАНОВКА И ЗАПУСК
--------------------------------------------------------------------

1. Один раз при установке на новом компьютере:

       python install_rec.py

   Проверит систему, покажет чего не хватает и спросит подтверждение
   перед тем как что-то скачивать и ставить.

2. Каждый раз, когда нужно записывать:

       python recorder_ui.py

   Через 3 секунды после запуска программа САМА начинает запись
   (можно отменить, кликнув на кнопку во время обратного отсчёта).


--------------------------------------------------------------------
ОКНО ПРОГРАММЫ — ЧТО ЕСТЬ ЧТО
--------------------------------------------------------------------

Строка управления:
  ● Начать запись / ■ Остановить запись  — главная кнопка
  🎤 Микрофон                             — заглушить/включить микрофон
                                             (активна только во время записи)
  Авто-вкл. по уровню                     — если микрофон заглушен и ты
                                             начал говорить — включится сам
                                             (активен только во время записи)
  ⚙ (шестерёнка, справа)                  — открыть/закрыть панель настроек
                                             (наведи — покажет подсказку)
  Таймер справа                           — общее время текущей записи

Уровни звука (RMS) — две шкалы (микрофон / динамики):
  зелёный  — тише порога тишины
  жёлтый   — 65–100% от порога
  красный  — громче порога (речь пишется)
  белая черта — сам порог

Строка статуса:
  серый кружок           — ожидание речи
  красный (мигает)       — идёт запись фрагмента
  🗑 Удалить WAV / MP3    — удалить все накопленные за сессию файлы
                             этого формата (спросит подтверждение)
  📂 Открыть фрагменты     — открыть папку с фрагментами (доступна,
                             только если включена "Запись фрагментов")
  📂 Открыть записи        — открыть папку с основной (полной) записью

Список "Записанные файлы":
  Скрыт во время записи, чтобы не занимать место — появляется после
  остановки. Копится за всю сессию (не очищается при повторном
  нажатии "Начать запись"). Двойной клик по файлу — открыть его.


--------------------------------------------------------------------
НАСТРОЙКИ (за шестерёнкой ⚙)
--------------------------------------------------------------------

Программа всегда пишет ОДИН сплошной файл full_*.mp3 от старта до
остановки — это основная, всегда включённая запись, её нельзя
отключить. Дополнительно она может НАРЕЗАТЬ звук на отдельные
файлы rec_* по паузам в речи — это отдельная, отключаемая функция
("Запись фрагментов").

  Папка для записи        Куда сохраняется основной файл full_*.mp3.

  Порог тишины (RMS)      50–5000, по умолчанию 500. Громкость, ниже
                           которой считается тишиной. 500–800 — норма
                           для обычной речи, ниже — чувствительнее к
                           тихим/шумным условиям. Меняется "на лету"
                           во время записи.

  Время откл. при тишине  Минуты (0 = выкл). Если вообще нет звуков
                           дольше этого времени — запись остановится
                           сама. Защита от "забыл остановить".

  Битрейт MP3              64/96/128/192/320 кбит/с. 128 — обычно
                           достаточно и для голоса, и для Whisper.

  Запись фрагментов ☐      Если включено — ниже становятся доступны
                           настройки нарезки (см. дальше). Если
                           выключено — они гаснут, пишется только
                           основной full_*.mp3 без нарезки.

  --- ниже доступно только если включена "Запись фрагментов" ---

  Папка для фрагментов     Куда сохраняются rec_*.mp3/.wav.

  Длительность паузы       0.3–10.0 сек. Сколько тишины нужно, чтобы
                           закрыть текущий фрагмент и начать ждать
                           следующий.

  Мин. длит. речи           Фрагменты короче этого не сохраняются —
                           отсекает случайные шумы (кашель, стук).

  Мин. время записи        Минуты (0 = выкл). Пока не прошло N минут
                           с начала фрагмента — тишина игнорируется,
                           фрагмент не закрывается раньше срока.

  Формат файла              MP3 (компактнее) или WAV (без сжатия,
                           точнее для Whisper).

  Микрофон / Системный звук   Выбор конкретного устройства записи.
                           "Авто" — устройство по умолчанию. Кнопка
                           ↻ — обновить список после подключения
                           нового оборудования.

Состояние панели настроек (открыта/закрыта) и все значения выше
запоминаются автоматически и восстанавливаются при следующем запуске.


--------------------------------------------------------------------
КАК РАБОТАЕТ ОПРЕДЕЛЕНИЕ РЕЧИ (для нарезки на фрагменты)
--------------------------------------------------------------------

  ОЖИДАНИЕ --> РЕЧЬ --> ТИШИНА --> ОЖИДАНИЕ (новый фрагмент)
                 ^         |
                 +---------+   (звук вернулся раньше конца паузы)

ОЖИДАНИЕ: копим короткий буфер (0.25 сек) на случай начала речи, чтобы
не срезать первое слово. Уровень превысил порог — переходим в РЕЧЬ.

РЕЧЬ: пишем. Уровень упал ниже порога — переходим в ТИШИНА.

ТИШИНА: продолжаем писать (на случай что речь возобновится). Тишина
длится дольше "Длительности паузы" — сохраняем фрагмент (с небольшим
хвостом 0.35 сек, чтобы не срезать окончания слов) и возвращаемся в
ОЖИДАНИЕ.

Основная (full_*) запись всё это не касается — она пишется сплошным
потоком независимо от состояния этого автомата.


--------------------------------------------------------------------
РЕКОМЕНДУЕМЫЕ НАСТРОЙКИ
--------------------------------------------------------------------

Zoom-конференция:
  Порог тишины:        500-700
  Длительность паузы:  1.5 сек
  Мин. длит. речи:     0.5 сек (вкл)
  Формат:              WAV или MP3 128 кбит/с
  Системный звук:      Авто

Запись лекции / монолога:
  Порог тишины:        400-600
  Длительность паузы:  3.0 сек
  Мин. длит. речи:     1.0 сек
  Мин. время записи:   2.0 мин
  Формат:              WAV

Длинное совещание без присмотра:
  Длительность паузы:      2.0 сек
  Время откл. при тишине:  30 мин

Нужен только один цельный файл, без нарезки на фрагменты:
  Запись фрагментов:   выкл
  (остальные настройки нарезки в этом случае скрыты и не важны)


--------------------------------------------------------------------
УДАЛЁННОЕ ИСПОЛЬЗОВАНИЕ (Zoom-конференции)
--------------------------------------------------------------------

Для записи через удалённый доступ используй Parsec, AnyDesk или
TeamViewer — они подключаются к обычной консольной сессии, где видны
все физические аудиоустройства.

RDP (встроенный "Подключение к удалённому рабочему столу" Windows) НЕ
подходит — он создаёт отдельную сессию с виртуальным звуком, реальный
микрофон и динамики компьютера из неё не видны.

Порядок действий:
  1. Подключись через Parsec/AnyDesk/TeamViewer
  2. Запусти Zoom, зайди на конференцию
  3. Запусти recorder_ui.py, нажми "Начать запись"
  4. Можно отключиться от Parsec/AnyDesk — recorder_ui.py продолжит
     работать в консольной сессии сам по себе
  5. Подключись снова, когда нужно остановить запись
